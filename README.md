\# AllOiz MediaSync



AllOiz MediaSync ist ein Windows-Programm zur Analyse und Vorbereitung von Mediendateien.



\## Aktueller Funktionsumfang



\- Mediendateien erkennen

\- Metadaten mit FFprobe auslesen

\- Audiospur mit FFmpeg als WAV extrahieren

\- Projektordner erstellen

\- projekt.json erzeugen

\- README.txt erzeugen

\- Projekt als ZIP-Datei verpacken



\## Voraussetzungen für die Entwicklung



\- Python 3

\- FFmpeg und FFprobe

\- Git

python app.py
